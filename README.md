# ScatterShot GIF

An OBS Lua script that picks random GIFs from a folder and flies them across a scene.

## Setup

1. Create a scene (default name `GIF_CONTAINER`) and add it as a **Scene** source on top of your main scene.
2. In OBS: **Tools → Scripts → +**, pick `scattershot_gif.lua`.
3. In the script panel, set the GIF folder and target scene, then tune speed, scale, spawn interval and the max number of GIFs on screen.

The buttons **Reload GIF folder** (after adding new files) and **Clear GIFs on screen** are in the same panel.
